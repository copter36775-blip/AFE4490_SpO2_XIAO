AFE4490 SpO2 · XIAO nRF52840

A TI AFE4490 pulse-oximetry front end on a Seeed XIAO nRF52840 Sense — firmware, a single-file browser console, and a MATLAB / Excel analysis path.

Open a console

Each is one self-contained HTML file: no build step, no CDN, no install. Chrome or Edge only — Firefox and Safari implement neither Web Serial nor Web Bluetooth.

current Studio V4 Everything below, plus the Register Lab — all 49 registers bit by bit, the four-phase timing editable to scale, a datasheet rule check, and capture by count, duration or around a register write. Studio V3 Monitor, Capture and Math over USB or Bluetooth. Studio V2 Adds the Math view: every formula evaluated on the signal in front of you. Studio V1 The stable one. Monitor and Capture, USB only.
Bluetooth needs this hosted page. Chrome treats a file:// origin as trustworthy enough for Web Serial but not for Web Bluetooth, so the BLE button only works from an https:// or localhost origin. Opening V3 or V4 from here is the easiest way to get it. USB works either way, including straight from a downloaded file.

What is in the repository

PathWhat it is
src/ Firmware V2.1.0 for the XIAO nRF52840. Protocol A1 over USB CDC and a BLE Nordic UART Service, with multi-register transactions that halt the sequencer for a timing change and report the exact sample it took effect on.
web/ The four consoles.
Analysis/ MATLAB toolkit and the Excel template. Reads our captures, TI EVM logs and the lab's own files; computes both SpO2 algorithms, pulse rate and perfusion index. Checked against TI's own GUI on the same recording: 95.50 % against 95.65 %.
Processing/ The university Lab 7 package as received, untouched, with a zip backup.
tools/ Test harnesses — link parser, renderer, BLE transport, register transactions on real hardware.
docs/ The wire protocol and the renderer notes.

Wiring

H1.1 VCC → 3V3  ·  H1.12 GND → GND
H1.7 CS0 → D0  ·  H1.8 MOSI → D1  ·  H1.9 SCK → D2
H1.10 MISO → D3  ·  H1.11 DRDY → D4  ·  SW1 → D5

Built for a NIMT internship, against the TI AFE4490 datasheet (SBAS602H). See README.md for the full write-up and Analysis/README.md for the lab workflow.
